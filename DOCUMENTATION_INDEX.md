# CaseVault — Design Documentation Index

This is the design-baseline documentation for the CYC386 secure software sprint.

## Required course artifacts

- [`PNE_Report.md`](PNE_Report.md): Phase 2 protection needs, assets, stakeholders, CIA mapping, requirements and planned verification.
- [`THREAT_MODEL.pdf`](THREAT_MODEL.pdf): Phase 3 DFDs, STRIDE assessment, attack trees, CVSS v3.1 risk and residual-risk discussion.

## Supporting project records

- [`TEAM.md`](TEAM.md): Team roster and evidence/approval status.
- [`docs/phase1/`](docs/phase1/): Proposed theme, application architecture, and five-vulnerability coverage.
- [`docs/phase2/`](docs/phase2/): PNE PDF and structured traceability/Jira planning CSVs.
- [`docs/phase3/`](docs/phase3/): Detailed threat catalog, CVSS register, DFD/attack-tree sources, model verification scripts, and evidence capture guide.

**Evidence policy:** The risk scenarios in these files are *modeled*, not confirmed production findings. Approval records, actual vulnerability evidence, scan logs, GitHub Actions runs, and Jira issue keys will be added only after they exist. No sensitive or real-world incident data may be committed to this public repository.

**Follow-up:** This package is to be committed on the `docs/phase1-3-security-design` feature branch and reviewed by another team member in a pull request before merging into the protected `main` branch.
